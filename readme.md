# Customer Churn Analysis Project

![Churn Analysis Dashboard](./reports/cover_image.jpg) 

## [📌 Project Overview](./readme.md)
**[Objective](./readme.md):** Identify key drivers of customer churn and build predictive model to reduce attrition  
**[Industry](./readme.md):** Telecom/Subscription Services
**[Tools Used](./readme.md):** Python, Pandas, Scikit-learn, Matplotlib/Seaborn, Jupyter Notebook  

**[Key Deliverables](./readme.md):**
- Exploratory Data Analysis (EDA) Notebook
- Strategic Recommendations Report

## [🔍 Business Questions Explored](./readme.md)

### 1. [Customer Demographics & Churn Risk](./readme.md)
- What age segments show highest churn propensity?
- Is there gender-based variation in retention patterns?

### 2. [Customer Loyalty Analysis](./readme.md)
- How does tenure length correlate with retention rates?
- What's the "danger zone" for customer attrition (tenure months)?

### 3. [Service Engagement Metrics](./readme.md)
- Is usage frequency predictive of churn behavior?
- How does recency of last interaction impact retention?

### 4. [Financial Indicators](./readme.md)
- What payment delay thresholds trigger churn?
- Is there spending pattern difference between retained/churned customers?

### 5. [Operational Factors](./readme.md)
- How do support call volumes relate to attrition rates?
- Which subscription types have highest retention potential?
